# Експериментальний стенд для магістерського дослідження
**Порівняльний аналіз моделей персоналізованого мультикритеріального ранжування гардеробу**

---

## 1. Архітектурний огляд

Цей каталог містить автономний, ізольований експериментальний стенд, розроблений для дослідження та оцінки трьох математичних моделей персоналізованого ранжування одягу на однакових вхідних сценаріях та сліпому експертному оцінюванні:

1. **M1 — Production Baseline**: Повністю відтворює базовий алгоритм Match Score (`js/match-score.js`).
2. **M2 — Unified Feedback Model**: Зберігає базові критерії та ваги, але нормалізує фідбек у єдину репрезентацію (`like = 1.0`, `unseen = 0.5`, `dislike = 0.0`) зі спільним знаменником.
3. **M3 — Optimized Weights Model**: Модель зі структурою M2, ваги якої оптимізуються строго на калібрувальній вибірці (сценарії 1–10) за цільовою функцією максимізації $\text{mean nDCG@8}$. Тестова вибірка (сценарії 11–25) використовується тільки для фінальної перевірки генералізації.

## 3. Математичні моделі

### Вектор критеріїв та ваги M1 / M2:
- $w_{\text{event}} = 0.15$
- $w_{\text{style}} = 0.15$
- $w_{\text{season}} = 0.10$
- $w_{\text{weather}} = 0.15$
- $w_{\text{body}} = 0.10$
- $w_{\text{color}} = 0.10$
- $w_{\text{semantic}} = 0.10$
- $w_{\text{rating}} = 0.05$
- $w_{\text{feedback}} = 0.10$
- Сума ваг: $\sum w_i = 1.00$.

### Відмінність M1 та M2:
У моделі **M1** за наявності фідбеку в сесії річ без прямої взаємодії вилучає вагу `feedback` із знаменника $\text{maxPossible}$.
У моделі **M2** вага `feedback` є спільною для всіх кандидатів у сесії:
- `like` $\to 1.0$
- `unseen` $\to 0.5$ (нейтральний апріорний базис)
- `dislike` $\to 0.0$

### Модель M3:
Оптимізує $W = (w_1, \dots, w_9)$ на симплексі $\sum w_i = 1.0, w_i \ge 0$ для максимізації $\text{mean nDCG@8}$ виключно на сценаріях 1–10 після завершення експертного оцінювання.

## 4. Порядок проведення дослідження

1. **Відкрити вебінтерфейс експертного оцінювання:**
   ```bash
   # Відкрити у браузері:
   experiments/evaluation.html
   ```
2. **Провести сліпе оцінювання речей та образів для сценаріїв 1–25:**
   - Шкала оцінювання речей:
     - `0` — Не підходить (суперечить умовам чи запиту);
     - `1` — Частково підходить (допустима, але є компроміси);
     - `2` — Підходить (добре відповідає контексту).
   - Шкала оцінювання основного образу:
     - `0` — Невдалий образ;
     - `1` — Загалом допустимий;
     - `2` — Цілісний гармонійний образ.
3. **Експортувати результати:**
   - Натиснути кнопку «💾 Експорт JSON»;
   - Зберегти експортований файл як `experiments/data/evaluations.json`.
4. **Запустити оптимізатор ваг M3:**
   ```bash
   node experiments/scripts/run_optimizer.js
   ```
5. **Розрахувати фінальні метрики:**
   ```bash
   node experiments/scripts/calculate_metrics.js
   ```
